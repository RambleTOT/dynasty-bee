# UI_KIT_tokens.md — цвета и шрифт платформы диспетчера

Решение 27.09.2026: открытой дизайн-системы у оператора связи нет (фирменная — коммерческая). Берём **цвета оператора связи + официальный логотип + шрифт Onest** вместо фирменного шрифта.
Цель: выглядеть как внутренний инструмент оператора связи.

## Откуда цвета
- **Факт:** пиксели скриншота приложения оператора связи (Figma `ЛЦТ`, node 187:3).
- **Факт:** скриншот снят на iPhone в Display P3, а Figma отдаёт значения без конвертации. После пересчёта P3 → sRGB жёлтый `#F6CA44` = **`#FFC800`**, светло-жёлтый `#F9DA5B` = **`#FFD939`**. Это совпадает с Brandfetch (`#FFC800` / `#FFD93A`). Серые при пересчёте сдвигаются на 1–2 единицы, поэтому берём их как есть.
- **Факт:** Brandfetch beeline.ru — `#FFC800`, `#FFD93A`, `#191C22`, `#FFFFFF`. https://brandfetch.com/beeline.ru
- Сверить с живым CSS beeline.ru не удалось: сайт не открылся ни из браузера, ни из среды.

| Чистый чёрный | — | `#000000` | только буквы логотипа и системный статус-бар. В UI не используем |

## Как оператор связи применяет акцент (из скриншота)
- Жёлтый — **редкий**: логотип, одна промо-карточка, иллюстрации. Кнопки и контролы не жёлтые.
- Активное состояние показывают **контрастом, а не цветом**: белый сегмент на сером треке + тёмный текст; активный таб — тёмный `#292F3D`, неактивные — `#9098AD`.
- Вторичная кнопка — белая «пилюля» с тёмным текстом на сером фоне («подробнее»).
- Иерархия фонов строится чередованием `#F0F3F5` ↔ `#FFFFFF`. Тени почти не используются.
- Формы: крупные скругления карточек (~24 pt), кнопки и контролы — полностью скруглённые «пилюли».
- [Г] Главный CTA на сайте/в приложении — жёлтая кнопка с тёмным текстом. На этом скрине его нет, проверить на beeline.ru вручную.

## Для нашего диспетчера [Д]
- Главная кнопка («Распределить», «Перепланировать») — `--accent` + `--on-accent`. **Одна на экран.**
- Остальные кнопки — белая пилюля (на сером фоне) или серая `--bg-control` (на белом).
- Выбранный инженер или заявка в списке — белая карточка + тёмная рамка/текст, без жёлтого. Жёлтый оставляем для CTA и ключевых метрик.
- Статусы (нарушение окна, неназначенная заявка) — отдельная семантическая палитра, в бренде её нет. Подобрать отдельно.

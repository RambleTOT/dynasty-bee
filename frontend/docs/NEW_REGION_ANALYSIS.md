29.09. Только анализ, код не менялся. Источники: фронт (`src/`), схема API (`src/api/schema.d.ts` от живого `/openapi.json`), код бэка `5314f05` — копия с сервера (`app/services/beeline_import.py`, `app/core/regions.py`, `app/api/routes/data.py`). **Ф** — проверено по коду или схеме, **[Г]** — гипотеза и как проверить.

**Главное.** Файл другого участка эксперт положит в одну из трёх карточек — по-другому у нас нельзя. Импорт пройдёт без ошибки, но день посчитается **бригадами выбранного участка, от его офиса**, а точки без геокодера лягут вокруг этого офиса. Ошибки эксперт не увидит — увидит правдоподобный, но неверный план.

## 1. Что будет сейчас

## 6. Черновик правки бэка — будущий §14 (в BACKEND_FIXES_FINAL пока не вставляем)

`POST /data/import-beeline` — новое поле `region_name?`. Если `region_id` не из известных и офис не распознан:
- участок `custom-<8 символов sha1 адреса офиса>`, название — `region_name` или адрес офиса, офис — геокодинг строки «Адрес Офиса» (нет — 409 `OFFICE_REQUIRED`);
- бригады: контрольный файл — по колонке «Бригада»; нет — N ≈ заявки / 5,5, минимум 3; «Подключение» и «Локальные» у всех, «Аварийные» — у каждой 4-й; автомобиль; 10–22; старт — офис [Д];
- координаты: кэш → геокодер → центр района → офис;
- `GET /regions` отдаёт и созданные участки.

Отчёт импорта — плюс `region_created: bool`, `geocoded_exact`, `geocoded_district`, `geocoded_office`, `engineers_source: "control" | "rule"`. Приёмка: выданный CSV Югоцентра с подменённой строкой офиса → новый участок, 5+ бригад, точки не у офиса Югоцентра, день открывается по `?region=custom-…`, три участка кейса не изменились.

## 8. План проверки

- **Файлы:** (а) CSV Югоцентра, строка офиса заменена на адрес другого района (например, «г. Москва, ул. Тверская, д. 7»); (б) 15–20 строк с новыми реальными адресами Подмосковья; (в) (б) в UTF-8; (г) без строки офиса; (д) с незнакомым BK.
- **Где:** только локальный бэк (копия с SQLite) или Югоцентр на стенде на **завтрашнюю** дату. Восток не трогаем: импорт заменит CSV-день участка.
- **Смотрим:** отчёт импорта, «Построить план», карту (точки не у офиса), «Сравнение», что три участка и демо-дни не изменились.

## 9. Черновик раздела README «Проверка на своём файле» (уровень 0)

> **Проверка на своём файле.** Сервис рассчитан на три участка кейса — Восток, Юго-восток, Югоцентр — с их бригадами и офисами. Файл заявок: CSV в cp1251 или UTF-8, разделитель `;`, колонки «Заявка», «Тип заявки BK», «Начало», «Окончание», «Адрес» обязательны; «Тип заявки HD», «Район», «Гигабитное подключение», «Подключение» — по желанию; последняя строка «Адрес Офиса;…» — необязательно. Контрольный файл — те же строки плюс «Статус BK» и «Бригада»: по нему считается колонка «Реальный диспетчер». Загрузка: «Загрузить CSV» → карточка участка → дата → «Загрузить» → «Открыть день» → «Построить план». Файл другого участка посчитается бригадами и от офиса выбранной карточки, а адреса без геокодера встанут вокруг этого офиса — для честной проверки берите файлы трёх участков кейса.
